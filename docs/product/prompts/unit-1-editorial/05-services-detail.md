# Unit 1 — Editorial — Service detail page (conditional)

Attach: `liora/05` (numbered service cards with per-service pricing)

## ⚠️ Ships only if the content gate is met

This page exists to rank for "modular kitchen designer Patna" — a search a homepage services
*section* cannot win. But a set of near-identical service pages generated from one template with
swapped nouns is a **doorway page**, which Google penalises, and the penalty lands on the client's
domain, not ours.

**Gate: no service page ships without one real project for that service and 150+ words of content
unique to it.** If the studio can only supply that for two services, ship two. Two real pages beat
five thin ones, and they carry no penalty risk.

Paste `00-identity-system.md` first, then this:

```
Design the SERVICE DETAIL page for one service: "Modular Kitchen Design".

NAV — per Global Chrome, white background, not overlaid.

Structure:
- Two-tone heading: "MODULAR / KITCHENS"
- Small uppercase eyebrow above it, broken across 2–3 lines: "WHAT WE DO / IN PATNA HOMES"
- An opening paragraph, 150–200 words, specific to this service — what's involved, what decisions
  the client will face, what it typically costs and how long it takes
- A "from ₹X per sq ft" price line, prominent (the pricing convention from Liora's services page)
- 4–6 photos of this service specifically, square corners, offset outline frame on the lead image
- A short "what's included" list — 4–6 items, ghost-numbered
- One real project using this service, presented as a compact card linking to its full case study:
  title, location, duration, one photo
- FAQ specific to this service, 3 questions, "+" accordion
- Gold CTA: "Get a kitchen estimate on WhatsApp"
- FOOTER — per Global Chrome spec

REQUIRED: at least 2 signature devices.

ANTI-GOALS: same as the home page. Additionally — this page must not read as a template with the
service name swapped in. The photos, the copy, the FAQ and the linked project all have to be
specific to this one service. If it could be turned into the "false ceiling" page by
find-and-replace, it is a doorway page and it should not ship.
```
