# Unit 4 — Bold Modern — Project / case-study detail

Attach: none required

Paste `00-identity-system.md` first, then this:

```
Design the PROJECT DETAIL page for one project: "3BHK, Boring Road".

NAV — per this identity's Global Chrome variant, on a white or black opening block.

Structure — a case study, not a bare gallery:
- Title, location "Boring Road, Patna", room type "Residential — 3BHK", budget range
  "₹8–10 lakh", duration "45 days" — displayed as a bold, high-contrast metadata block, not
  buried as small print
- 8–10 photos, duotone or high-contrast treatment, square or diagonally-cropped
- A 300–400 word description: the client's brief, our approach, 2–3 key design decisions, the
  outcome
- One client quote with name and area (sample/placeholder content, marked visibly as such)
- Red-orange CTA: "Discuss your project on WhatsApp"
- Previous / next project navigation at the bottom
- FOOTER — per this identity's Global Chrome variant

Use bold filled numerals for section markers, not outline/ghost numerals.

ANTI-GOALS: no ghost/outline numerals, no soft rounded corners, no muted restraint. Otherwise no
SaaS pattern, no purple/blue/teal, no glassmorphism.
```
