# Unit 4 — Bold Modern — Estimate calculator

Attach: none required

Paste `00-identity-system.md` first, then this:

```
Design the ESTIMATE CALCULATOR page. Keep it simple — a light interactive tool, not a major
feature.

NAV — per this identity's Global Chrome variant.

Inputs: carpet area (sq ft slider, bold red-orange fill), home type (1/2/3/4 BHK, bold-bordered
selectable blocks), finish level (Essential / Premium / Luxe, bold-bordered selectable blocks).
Output: a price RANGE (e.g. "₹6.5 – 8.2 lakh"), clearly labelled "Indicative estimate", updating
live as inputs change. Below the result: red-orange CTA "Get an exact quote on WhatsApp".

Bold caps heading: "CALCULATE THE ESTIMATE". Show the pre-interaction state — sensible defaults
already selected, result already visible, on a full-bleed black or white block.

FOOTER — per this identity's Global Chrome variant.

ANTI-GOALS: no ghost numerals, no soft rounded corners. Never show a single number without
"indicative" labelling — always a range.
```
