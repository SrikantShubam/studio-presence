# Unit 2 — Premium — Estimate calculator

Attach: none required

Paste `00-identity-system.md` first, then this:

```
Design the ESTIMATE CALCULATOR page. Keep it simple — a light interactive tool, not a major
feature.

NAV — per this identity's Global Chrome variant, cream background.

Inputs: carpet area (sq ft slider), home type (1/2/3/4 BHK, selectable), finish level (Essential /
Premium / Luxe, selectable). Output: a price RANGE (e.g. "₹6.5 – 8.2 lakh"), clearly labelled
"Indicative estimate", updating live as inputs change. Below the result: moss-green CTA "Get an
exact quote on WhatsApp".

Sentence-case serif heading: "Calculate your estimate". Show the pre-interaction state — sensible
defaults already selected, result already visible. Rounded input controls (this identity's
convention), not sharp-edged.

FOOTER — per this identity's Global Chrome variant.

ANTI-GOALS: no all-caps headings, no ghost numerals. Never show a single number without
"indicative" labelling — always a range.
```
