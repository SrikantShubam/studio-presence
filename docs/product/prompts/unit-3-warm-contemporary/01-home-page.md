# Unit 3 — Warm Contemporary — Home page

Attach: none — no direct reference exists for this identity, expect more iteration than the other units

Paste `00-identity-system.md` first, then this:

```
Design the complete HOME PAGE for Ashish Interiors in this identity, desktop, top to bottom, same
section list and order as Unit 1 (hero → quick-actions → trust element → services → projects →
about → process → testimonials → Instagram → FAQ → contact → footer), expressed entirely in the
Warm Contemporary visual language:

1. NAV — per this identity's Global Chrome variant.
2. HERO — full-bleed or generously-margined photo with rounded corners, warm colour-wash overlay,
   friendly headline (not condensed, not all-caps), terracotta pill CTA "Book a free consultation".
3. QUICK-ACTIONS ROW — WhatsApp · Call · Directions · Instagram, rounded pill buttons.
4. TRUST ELEMENT — keep any numbers here softer, embedded in prose rather than a bare stat band —
   e.g. "12+ years designing homes across Patna" as a sentence, not "12+ / YEARS".
5. SERVICES — rounded image cards, soft organic accent shape behind the section heading.
6. FEATURED PROJECTS — a friendly grid, generous rounded corners, warm colour-wash unifying mixed
   photo quality.
7. ABOUT — owner photo with rounded corners, warm and personal tone.
8. PROCESS — 4 steps, rounded numbered badges (soft, not sharp ghost numerals), a soft connecting
   line.
9. TESTIMONIALS — featured quote + card grid, rounded cards, soft shadow-free depth via colour only.
10. INSTAGRAM STRIP — rounded tiles matching the rest of the page.
11. FAQ — friendly rounded accordion, "+" icons, soft dividers (not hairlines — slightly heavier,
    warmer).
12. CONTACT — phone, WhatsApp, address, hours, map, terracotta CTA repeated.
13. FOOTER — per this identity's Global Chrome variant.

REQUIRED: at least 2 signature devices from this identity's list.

ANTI-GOALS: no square corners, no ghost numerals, no offset outline frames (Editorial's devices).
No stat-block-as-clean-row styled like Premium — keep any numbers here softer, embedded in prose.
Otherwise: no SaaS centred-hero pattern, no purple/blue/teal (sage is the only green-adjacent tone
permitted), no glassmorphism.
```
