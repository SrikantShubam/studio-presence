# Unit 3 — Warm Contemporary — Project / case-study detail

Attach: none required

Paste `00-identity-system.md` first, then this:

```
Design the PROJECT DETAIL page for one project: "3BHK, Boring Road".

NAV — per this identity's Global Chrome variant, cream background, no hero photo.

Structure — a case study, not a bare gallery:
- Title, location "Boring Road, Patna", room type "Residential — 3BHK", budget range
  "₹8–10 lakh", duration "45 days" — presented warmly, e.g. as a soft rounded info card rather than
  a stark metadata row
- 8–10 photos, generously rounded corners (16–24px), warm colour-wash unifying mixed photo quality
- A 300–400 word description: the client's brief, our approach, 2–3 key design decisions, the
  outcome
- One client quote with name and area (sample/placeholder content, marked visibly as such)
- Terracotta pill CTA: "Discuss your project on WhatsApp"
- Previous / next project navigation at the bottom
- FOOTER — per this identity's Global Chrome variant

ANTI-GOALS: no square corners, no ghost numerals, no offset outline frames. No stark metadata rows
— keep the information warm and embedded. Otherwise no SaaS pattern, no purple/blue/teal, no
glassmorphism.
```
