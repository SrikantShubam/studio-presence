# Unit 3 — Warm Contemporary — Estimate calculator

Attach: none required

Paste `00-identity-system.md` first, then this:

```
Design the ESTIMATE CALCULATOR page. Keep it simple — a light interactive tool, not a major
feature.

NAV — per this identity's Global Chrome variant, cream background.

Inputs: carpet area (sq ft slider, rounded track and thumb), home type (1/2/3/4 BHK, rounded
pill-selectable), finish level (Essential / Premium / Luxe, rounded pill-selectable). Output: a
price RANGE (e.g. "₹6.5 – 8.2 lakh"), clearly labelled "Indicative estimate", updating live as
inputs change. Below the result: terracotta pill CTA "Get an exact quote on WhatsApp".

Friendly heading: "Let's estimate your project". Show the pre-interaction state — sensible
defaults already selected, result already visible. Soft organic accent shape behind the result card.

FOOTER — per this identity's Global Chrome variant.

ANTI-GOALS: no square corners, no ghost numerals, no all-caps headings. Never show a single number
without "indicative" labelling — always a range.
```
